## 归因脚本（改路径即可复用）

```python
import json, collections
rows = [json.loads(l) for l in open(r'$DSH_HOME\composite\main-usage.jsonl', encoding='utf-8') if l.strip()]
tin = sum(r.get('tokensIn', 0) or 0 for r in rows)
tout = sum(r.get('tokensOut', 0) or 0 for r in rows)
cost = sum(r.get('costUsd', 0) or 0 for r in rows)
cr = sum(r.get('cacheReadTokens', 0) or 0 for r in rows)
ri = sum(r.get('inputTokens', 0) or 0 for r in rows)
print('rows', len(rows), 'in', tin, 'out', tout, 'out%', round(tout / (tin + tout) * 100, 1),
      'cachehit%', round(cr / (cr + ri) * 100, 1), 'costUSD', round(cost, 4),
      'avgInPerStep', round(tin / len(rows)), 'maxIn', max(r.get('tokensIn', 0) or 0 for r in rows))
byturn = collections.defaultdict(lambda: [0, 0, 0, 0])
for r in rows:
    b = byturn[r.get('turn')]
    b[0] += r.get('tokensIn', 0) or 0; b[1] += r.get('tokensOut', 0) or 0
    b[2] += r.get('costUsd', 0) or 0; b[3] += 1
for t, b in sorted(byturn.items(), key=lambda x: -x[1][2])[:8]:
    print('turn', t, 'steps', b[3], 'in', b[0], 'cost', round(b[2], 4))
```

## 三个易踩的坑

1. 只看 `tokensIn` 会以为要压输入，其实 **97.3% 是缓存命中（便宜）**；真正贵的是未命中新输入与工具输出。
2. 输出 token 单价虽高 3–5 倍，但占比 0.3% 时压输出收益≈0；别被「输出贵」这句话带偏，先看占比。
3. 缓存命中率高 ≠ 没浪费：每轮仍要「读」22 万 token，工具输出越堆越肥，还会拖低后续命中率。

## 结论 → 插件动作

- 该装：`billion-context`（折旧历史，已装 `0.1.213`）、工具输出压缩类、`dsh-cost-meter`（持续观测）。
- 不该装：`dsh-thinking-levels` 等输出侧插件。
- 装前备份 `~/.dsh/profiles/desktop/` 的 5 个配置文件；装前装后各跑一次脚本，`costUsd` 没降就回滚。
