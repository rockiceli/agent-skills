**复用方法（下次装完照做）**
1. 比 `package.json` mtime 与 DSH 主进程 `StartTime`：`Get-Process -Name 'DeepSeek Harness' | Select Id,StartTime,MainWindowTitle | ConvertTo-Json`；`\/Date(ms)\/` 是 Unix 毫秒，用 `datetime.timezone(timedelta(hours=8))` 转（**别用 `zoneinfo`，本机无 tzdata**）。进程早于配置修改就必须重启，否则必是旧 bundles。
2. 找运行时清单：在 `%APPDATA%\@deepseek-ai\dsh-desktop\Code Cache\js\` 用 Python 读字节搜 `dsh-app://app/plugins/??`，能列出全部被加载的 `client.js`（二进制 V8 缓存，Grep 工具搜不到）。
3. 截屏：PowerShell `Add-Type`（连 `-AssemblyName` 也）被安全策略拒绝；改用 Python `ctypes.windll.user32`（`FindWindowW`/`SetForegroundWindow`/`mouse_event`）+ `PIL.ImageGrab`（托管 Python 3.13.12 自带 PIL 13.0.0）。侧栏「插件」约 (60,157)，滚到「已安装插件」看中文别名。
4. **无 client 的纯 Node hook 插件（如 `cc-safety-net`）不会出现在这个清单和 GUI 已安装列表里**，别误判成漏装；验证它只能触发一次工具调用看拦截，本次未做 → 标「未验证」。
