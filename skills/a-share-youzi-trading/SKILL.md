# A股游资短线 · 情绪周期与纪律执行

目标：把「游资心法」从故事变成**可执行、可量化、可复盘**的纪律，用于 A股短线模拟交易与复盘。
定位：**方法论与风控框架**，不是收益承诺，也不直接下单。

## 何时用 / 不用

用：
- 判断「今天能不能做、该空仓还是重仓、做到几成仓」；
- 判断情绪周期处在哪个阶段（冰点/启动/确认/高潮/退潮）；
- 选股范围：只做主线龙头、打板/低吸的具体条件；
- 持仓纪律：亏损单、炸板、回撤线、连续成功后降速；
- 每日/每周复盘，把情绪读数与交易日志对账。

不用：
- 代替 `A股抓龙运维` 做系统巡检/修流/调参（用那个）；
- 代替 `A股数据接入` 换取数源；
- 代替 `A股盘中买入`/`A股尾盘卖出` 的固定时间窗流程（那是执行层）；
- 作为个股推荐或买卖指令（本系统 LLM 不直接下单，交易必须经 `portfolio`）。

## 一、硬规则（不可协商）

1. **无数据不下结论**：没有当日涨停/跌停/炸板/连板/溢价数据，不判断市场、不点股。
2. **无市场背景不点股**：先定情绪阶段与主线，再谈个股。
3. **弱市不做**：冰点/退潮期可空仓；不为了“手痒”开仓。
4. **亏损单不过夜**：短线单当日走弱、次日不板，优先离场，不把短线拖成中线。
5. **不用杠杆、不追高、不摊平**：不融资、不补仓摊成本、不追后排。

软规则：只做龙头、永远不满仓、只做主升浪。

## 二、情绪周期：5 阶段与量化读数

| 阶段 | 特征（量化） | 相对仓位 |
|---|---|---|
| 冰点 | 涨停少、跌停多、炸板率高、连板高度 ≤2 | 0~20%（可空仓） |
| 启动 | 涨停回升、首板增多、炸板率下降 | 30~50% |
| 确认 | 连板梯队完整、1进2/2进3 晋级率抬升、赚钱效应转正 | 60~70% |
| 高潮 | 涨停家数/最高连板双高、全面普涨、后排也涨停 | 60~80%（兑现为主，不追后排） |
| 退潮 | 高位股断板/大面、炸板率升高、晋级率骤降 | 0~20%（先撤） |

核心指标（本项目 `sentiment` 已输出）：
- 涨停家数 `limit_up`、炸板家数 `broken`、跌停家数 `limit_down`；
- 炸板率 `blow_rate = broken / (limit_up + broken)`；
- 最高连板 `max_height`、连板家数 `lianban`；
- 赚钱效应：昨日涨停今日 `premium_median`（溢价中位）、`again_rate`（再涨停率）；
- 分层晋级率：`promote_1to2`（1进2；更高层同理）；
- **情绪分 `score = 涨停家数 × (1 + 最高连板) × (1 − 炸板率)`**，再看 20 日分位 `score_pct` 定阶段。

阶段判定口径（与 `engine/sentiment.py` 一致）：分位 ≥0.85 高潮、≥0.55 确认、≥0.25 启动、其余冰点；前一日确认/高潮且分数与高度回落 → 退潮；样本不足按确认（中性）处理。

## 三、选股：只做主线龙头

龙头三要素：
1. 三连板启动（高度由它打开）；
2. 先于大盘止跌/走强；
3. 能带动板块（同题材跟风）。

三类可打板（只打主线，不碰杂毛）：
- 主线首板（题材最硬、量价齐升）；
- 龙头弱转强二板（分歧转一致）；
- 高位反包板（龙头首阴后反包，需情绪确认期）。

低吸条件（只在龙头/主线上）：
- 龙头回调到关键支撑（前平台/均线/首板起点）；
- 或首次水下约 -5% 且放量止跌；
- 不在退潮期低吸高位股。

不做清单：后排跟风、杂毛题材、缩量阴跌抄底、越跌越买、补仓摊成本、满仓单票。

## 四、卖出与风控纪律

- **隔日不板就砸**：打板单次日不能封板/明显走弱即离场（90% 短线单次日结束）。
- **单笔亏损 >5% 或跌破关键均线止损**，不抱幻想，错了就割。
- **炸板离场**：封板被打开且回封无力，先减/先走。
- **退潮先撤**：情绪阶段转退潮，降仓/空仓，不逆势加仓。
- **回撤线（资金曲线）**：设约 10% 回撤线并随最高点移动；线之上可正常/重仓，触线分仓降速；回撤触及上一轮盈利起点，停手 3 天复盘。连续成功后警惕自信膨胀导致大亏。
- **分仓防连败**：单票不重仓，避免连续失败造成大回撤。

## 五、仓位与组合（与本项目风控的关系）

- 相对仓位档：强势 60~80%、震荡 30~50%、弱势 0~20%（与上表一致）。
- 本项目硬约束优先：`config/strategy.yaml risk.exposure_by_regime`（attack/neutral 0.90、defend 0.60）是总仓位上限；`max_positions=5`、单票 22%、每日新开仓 ≤2、账户回撤 8% 缩仓 0.5。
- 技能只给**相对档位建议**；最终计划由规则引擎生成，不得绕过 `portfolio` 的 T+1/整手/仓位校验。

### 波动率拖累：回撤线分仓的数学依据（2026-11-17 收录，BV1TTnF6cEL7 + WebSearch 多源核验）
- **g ≈ μ − σ²/2**（复利收益 ≈ 算术平均 − 半方差），来自 Jensen 不等式、二阶近似；杠杆 L 倍 → σ 变 L 倍 → 拖累 **L² 倍**。⇒ 给「回撤线分仓」补上依据：控回撤不是心理纪律，是在直接减 σ²/2。
- **四个坑**：① 近似非恒等式，σ>30% / 肥尾 / 短周期明显失真（σ=40% 时近似给 0%、精确值 1.28%）；② μ 与 σ 必须同期；③ 拖累不是费用、无法对冲，只能靠降波动改变收益序列；④ σ 用**自己策略净值**算，别拿指数代替。**失败教训 / 何时别用**：这是组合 / 资金曲线级的多期复利判据，短线单票 T+1、样本少、持有期短时假设不成立 → 别拿它给单票算仓位，只用于定总仓位与回撤线。

## 六、每日复盘清单（5 分钟）

1. 读情绪：`python -m engine.cli sentiment`（阶段/分数/分位/炸板率/最高连板/溢价）；
2. 读体检：`python -m engine.cli review`（胜率 50~56%、payoff、PF、MDD 是否在带内）；
3. 对账：今日买卖是否符合「只做主线龙头/弱市不做/亏损单不过夜」；
4. 归因：亏损来自情绪误判、追后排、还是执行滑点；只改可复现的规则问题；
5. 明日验证：写下「若 A 则 B」的条件，次日收盘对账。

## 七、接入本项目（抓龙系统）

- 情绪读数：`engine/sentiment.py` → `state/sentiment/<day>.json`；CLI `python -m engine.cli sentiment [--day] [--days N] [--json]`。
- 盘前/买入/尾盘 pack 已带 `sentiment`（只读参考，不改变规则计划）；`review` 输出带情绪行。
- 回测门控（默认关，仅实验）：`entries.backtest_sentiment_mode`（0 关/1 弱情绪跳过/2 弱情绪缩仓）、`backtest_sentiment_weak_pct`、`backtest_sentiment_scale`、`backtest_sentiment_window`。
- 输出给用户时遵守：先诊断（阶段/主线/风险）→ 依据（数据）→ 动作（做/不做/几成）→ 风险 → 缺失信息。

## 八、来源、许可与去噪

- 方法论主干：`AIPMAndy/youzi-trading-skill`（MIT，v2.0；23 位游资心法整理），本技能为其精简+本项目适配版。
- 案例：退学炒股「5万到千万」访谈（新浪转载）——情绪 5 阶段、只做主线龙头、回撤线分仓、隔日不板就砸。
- 情绪指标口径参考：`simonlin1212/vibe-astock`（情绪分公式/赚钱效应/晋级率/连板天梯）与 `quantskills/skill-b6-limitup-pool`（涨停池状态机/分层晋级率）；**未复制其代码**（后者 GPL-3.0）。
- 去噪：`wangpage/quant-ashare` 的诚实回测表明公开因子+LightGBM 真实 OOS 夏普天花板约 0.5~1.0，多数日频 IC 显著是重叠样本假象；真 alpha 需付费数据/Level2。故本技能只承诺**纪律与风控框架**，不承诺超额收益；任何仓位/门控上线前须做样本外验证。
